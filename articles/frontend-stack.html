Vue 3 技术栈：从分工到跑通一个页面

发布于 2026-01-27更新于 2026-10-15前端入门
文章目录

浏览器用 HTML 描述内容，用 CSS 控制外观，用 JavaScript 处理交互。页面变复杂后，需要把界面拆成组件、维护状态，再处理不同地址之间的导航。前端工具的价值，就在于帮助开发者管理这些工作。

下面从这些需求出发，说明 Vue 3、Vite、Vue Router、Tailwind CSS 和 daisyUI 的分工，再搭建一个包含计数按钮和页面导航的小应用。

各个工具解决什么问题

需求工具负责的工作
数据变化后更新界面Vue 3组织组件、跟踪响应式状态、处理事件
开发和发布代码Vite启动开发服务器、转换源码、生成生产构建
通过地址访问不同页面Vue Router把 URL 映射到组件，处理前进、后退和导航
编排布局与视觉样式Tailwind CSS提供间距、颜色、布局等工具类，减少手写 CSS
复用按钮等常见外观daisyUI在 Tailwind 基础上提供组件类和主题

这些工具围绕同一个应用协作。Vue Router 与样式系统各自独立；在下面的构建方案中，daisyUI 作为 Tailwind 插件使用。Vite 则在开发和构建阶段处理这些源码。

静态介绍页可以直接使用 HTML 和 CSS；只有一个交互区域时，也可以先只用 Vue。需要多个可访问的页面地址时，再加入路由。工具是否必要，取决于页面要完成的功能。

Vite 开发时按需处理源文件，也会预打包依赖。热更新能保留部分应用状态，遇到无法局部更新的改动时仍会重载页面。

创建 Vue 与路由项目

先安装 Node.js 24 LTS 的较新版本，至少 24.12。脚手架对 Node.js 的完整要求见 Vue 官方快速开始。在准备存放项目的目录执行：

npm create vue@latest my-vue-app -- --router
cd my-vue-app
npm install

--router 会让 Vue 官方脚手架加入路由、首页和关于页。这个例子使用 JavaScript，保留脚手架生成的 src/main.js 和 src/router/index.js。

截至 2026 年 10 月，当前脚手架使用 Vue Router 5。旧教程中的 Vue Router 4 也支持 Vue 3；对于手写路由配置，官方说明从 4 升级到 5 没有破坏性变化，详见 迁移说明。

接入 Tailwind 与 daisyUI

下面使用 Tailwind CSS 4 和 daisyUI 5，配置方式与 Tailwind 3 的旧教程不同。在项目目录安装：

npm install -D tailwindcss@4 @tailwindcss/vite@4 daisyui@5

在 vite.config.js 中导入并启用 Tailwind 插件。保留 Vue 插件、开发工具插件和路径别名，完整配置如下：

import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [vue(), vueDevTools(), tailwindcss()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})

将 src/assets/main.css 的内容替换为：

@import "tailwindcss";
@plugin "daisyui";

脚手架已在 src/main.js 中导入这个 CSS 文件，保留该导入。至此，安装依赖、启用构建插件、引入样式三个环节才完整。

Tailwind 的 p-6、flex 等类处理具体样式；daisyUI 的 btn、btn-primary 等类组合出按钮外观。项目仍然有 CSS 入口，也可以继续编写自定义 CSS。daisyUI 提供样式，点击后执行什么操作仍由 Vue 或原生 HTML 行为决定。

连接状态与页面导航

将 src/App.vue 替换为下面的内容。RouterLink 负责导航，RouterView 显示当前地址匹配到的页面：

<script setup>
import { RouterLink, RouterView } from 'vue-router'
</script>

<template>
  <main class="mx-auto max-w-3xl p-6">
    <h1 class="mb-6 text-3xl font-bold">我的 Vue 应用</h1>
    <nav class="mb-8 flex gap-2" aria-label="页面导航">
      <RouterLink to="/" class="btn btn-ghost">首页</RouterLink>
      <RouterLink to="/about" class="btn btn-ghost">关于</RouterLink>
    </nav>
    <RouterView />
  </main>
</template>

将 src/views/HomeView.vue 替换为一个计数按钮：

<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <section aria-labelledby="counter-title">
    <h2 id="counter-title" class="mb-4 text-xl font-semibold">计数示例</h2>
    <button type="button" class="btn btn-primary" @click="count++">
      已点击 {{ count }} 次
    </button>
  </section>
</template>

ref(0) 声明响应式状态；@click 修改状态；Vue 根据模板更新按钮文字。写在模板中的 ref 会自动解包。若在 JavaScript 代码中读写这个值，则使用 count.value。

关于页可以保留脚手架的示例，也可以将 src/views/AboutView.vue 替换为：

<template>
  <h2 class="text-xl font-semibold">关于这个应用</h2>
</template>

应用此时已有三类独立行为：Vue 更新计数，路由切换页面，Tailwind 与 daisyUI 控制外观。这个例子把计数保存在首页组件中，离开首页后再返回，计数会重置。需要跨页面保留数据时，再设计共享状态。

运行、检查与构建

npm run dev

打开终端显示的本地地址，依次检查：

  1. 点击按钮后数字递增，按钮显示 daisyUI 的样式。
  2. 点击“关于”后，地址变为 /about，页面内容随之切换。
  3. 浏览器的后退按钮可以回到首页。

检查完成后按 Ctrl+C 停止开发服务器，再执行构建和本地预览：

npm run build
npm run preview

build 会生成 dist/；preview 用于本地检查构建结果。正式部署时，将构建产物交给静态托管服务。

部署时的路由要求

脚手架默认使用 history 路由。部署后直接打开或刷新 /about，需要托管服务把未匹配的页面路径回退到 index.html。如果平台无法配置回退，可以选择 hash 路由；部署到子目录时还要配置 Vite 的 base。详见 路由模式和 Vite 部署指南。

有具体需求后再扩展

学习时先掌握 JavaScript 的模块、事件和异步操作，再理解 Vue 的模板、状态与组件通信。能解释上面的计数按钮后，再研究路由参数、导航守卫和更复杂的样式组织。

图片裁剪属于业务功能。出现头像上传等需求时，再选择裁剪库。例如，vue-croppie 的说明将其定位为 Vue 2 封装，不能直接照搬到 Vue 3。若使用原生 Croppie，需要在组件挂载后通过 DOM ref 创建实例，并在卸载时销毁；选型时也应核对维护状态和浏览器兼容性。
