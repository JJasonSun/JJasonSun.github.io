现代前端技术栈入门指南：
Vue 3 + Vite + Vue Router + Tailwind CSS + DaisyUI

2026-01-27 前端入门

一、核心框架：Vue 3

1.1 什么是 Vue 3？

Vue 3 是 Vue.js 的当前主力版本之一，也是这套技术栈的核心。它负责组织组件结构、响应式状态和页面交互逻辑。

1.2 核心特点

特性 说明
Composition API 按业务逻辑组织代码，更适合复用和拆分复杂页面
更好的 TypeScript 支持 和 TS 结合更自然，组件和组合式函数都更容易写出清晰类型
更高性能 基于 Proxy 的响应式系统，更新更精准，整体开销更低

1.3 学习资源

📘 Vue 3 官方中文文档 — 最权威的学习指南，包含从安装到进阶的完整教程

二、构建工具：Vite

2.1 为什么选择 Vite？

Vite 是现代前端构建工具，常被用来作为 Vue 项目的默认选择。它把开发体验和生产构建分开处理，重点解决启动慢、热更新慢这两个老问题：

  • ⚡ 秒级冷启动 — 利用浏览器原生 ES 模块，无需打包即可运行
  • 🔥 瞬时热更新（HMR） — 修改代码后页面即时响应，不刷新状态
  • 📦 优化的生产构建 — 输出适合部署的静态资源

提示：如果你是新项目，直接从 Vite 开始会更省心。

三、样式系统

3.1 Tailwind CSS — 原子化 CSS 框架

定位

负责页面布局与视觉样式，采用"工具类优先"（Utility-First）的理念。

与传统 CSS 的区别

传统方式 Tailwind CSS 方式
编写 .css 文件，自定义类名 直接在 HTML/模板中使用预定义工具类
需要思考类名命名（BEM 规范） 直接组合 flex、pt-4、text-center 等原子类
样式与结构分离 样式即结构，快速迭代

示例对比

<!-- 传统方式 -->
<style>
.card {
  padding: 1.5rem;
  border-radius: 0.5rem;
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}
</style>
<div class="card">内容</div>

<!-- Tailwind CSS 方式 -->
<div class="p-6 rounded-lg shadow-md">内容</div>

安装方式（Vite 项目）

📘 Tailwind CSS + Vite 官方安装指南

npm install -D tailwindcss @tailwindcss/vite

3.2 DaisyUI — 基于 Tailwind 的 UI 组件库

定位

在 Tailwind CSS 基础上提供语义化的组件层，让你无需从零搭建界面。

核心作用

功能 说明
现成组件 提供 Button、Card、Modal、Form、Navbar 等常用组件
主题系统 内置 35 款主题，可以快速切换不同视觉风格
语义化类名 使用 btn、card、modal 等直观类名，代替冗长的工具类组合

依赖关系

重要：DaisyUI 必须先安装 Tailwind CSS，它是对 Tailwind 的扩展而非替代。

使用示例

<!-- 纯 Tailwind：需要写很多工具类 -->
<button class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600 focus:outline-none focus:ring-2">
  提交
</button>

<!-- DaisyUI：语义化类名，简洁优雅 -->
<button class="btn btn-primary">提交</button>

学习资源

  • 📘 DaisyUI 安装文档
  • 📘 DaisyUI 组件文档 — 包含所有组件的视觉示例和代码片段

四、路由管理：Vue Router 4

4.1 作用

Vue Router 是 Vue.js 的官方路由管理器，负责单页应用（SPA）的页面导航：

  • 定义 URL 与组件的映射关系
  • 实现页面无刷新切换
  • 管理导航守卫、动态路由、路由参数等

4.2 与 Vue 3 的协同

Vue Router 4 专为 Vue 3 设计，完美支持 Composition API 风格：

// 组合式 API 风格的路由使用
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()  // 路由实例，用于编程式导航
const route = useRoute()    // 当前路由信息，获取参数等

五、图片处理：Croppie

5.1 定位

图片裁剪库，常用于需要用户上传并编辑图片的场景。

5.2 典型使用场景

  • ✂️ 头像裁剪 — 用户上传头像时进行选区裁剪
  • 🖼️ 图片上传前处理 — 限制尺寸、调整构图后再上传服务器

5.3 Vue 3 中的注意事项

注意：vue-croppie 插件不支持 Vue 3，课程中直接使用原生 Croppie 库，通过 ref 操作 DOM 方式集成。

七、学习路径建议

如果你是初学者，建议按以下顺序学习：

  1. Vue 3 基础 → 掌握模板语法、响应式数据、组件通信
  2. Vite 使用 → 了解项目结构、开发服务器、构建命令
  3. Tailwind CSS → 熟悉常用工具类、布局方式
  4. DaisyUI → 使用现成组件快速搭建界面
  5. Vue Router → 添加多页面导航能力
  6. Croppie → 按需集成图片处理功能

八、总结

技术 一句话定位 核心价值
Vue 3 前端核心框架 组件化开发、响应式数据、逻辑复用
Vite 现代构建工具 极速开发体验、优化生产构建
Vue Router 官方路由管理 单页应用导航、深度集成 Vue
Tailwind CSS 原子化样式框架 不写 CSS 文件、快速构建界面
DaisyUI Tailwind 组件库 现成组件、主题系统、语义化类名
Croppie 图片裁剪库 头像处理、上传前编辑

这套技术栈整体上偏向"少配置、快交付"：Vue 3 负责组件逻辑，Vite 负责开发与构建，Tailwind 负责样式编排，DaisyUI 负责常用界面组件。它们组合起来的好处很直接，就是能明显减少样板代码，让你更快把页面做出来。
