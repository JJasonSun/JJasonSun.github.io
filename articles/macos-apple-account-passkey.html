macOS：修改 Apple 账户通行密钥
显示的旧邮箱

2026-10-15macOS · 通行密钥

问题与实测结果

Apple 账户已改用新邮箱作为主要邮箱，旧邮箱已移除。但在 Chrome 登录 Apple 网站、调用 Apple「密码」中的通行密钥时，弹窗仍显示旧邮箱，且「密码」App 中找不到这条 Apple 账户通行密钥。

实测验证：启用 AuthKit → StandardPasskeys 后，以下方法有效，而且必须重启 Mac 才能生效。 不保证其他 macOS 版本或设备同样适用。

社区反馈与方案来源

  • 问题反馈： Reddit r/MacOS 的方案帖提到，Apple 账户更换邮箱后，通行密钥仍可能显示旧地址。相关讨论另见 Apple 支持社区。
  • 显示名称的含义： Apple 在 WWDC25《What’s new in passkeys》中说明，通行密钥的用户名是本地显示标签，认证时不会回传服务器。因此，仅显示旧邮箱不能证明旧邮箱仍是账户登录标识。
  • 解决方案： 上述 Reddit 方案帖给出了启用 AuthKit → StandardPasskeys、重启、编辑用户名及撤销开关的方法，标注适用于 macOS 27；另有 r/MacOSBeta 讨论。这是社区发现的实验性方法，并非 Apple 官方公开支持的修复流程。未确认 macOS 26 的适用性。

1. 启用功能开关

打开「终端」，执行：

sudo mkdir -p /Library/Preferences/FeatureFlags/Domain
sudo defaults write /Library/Preferences/FeatureFlags/Domain/AuthKit StandardPasskeys -dict Enabled -bool true

按提示输入 Mac 管理员密码，输入时终端不会显示字符。

执行成功后，必须重启 Mac。仅退出并重新打开「密码」App 不能替代重启。

2. 在「密码」App 修改用户名

重启后：

  1. 打开 Apple「密码」（Passwords）App，并解锁。
  2. 进入「通行密钥」（Passkeys），搜索 apple.com，找到对应的 Apple 账户条目。
  3. 打开条目，点击「编辑」。
  4. 将「用户名」中的旧邮箱改为新邮箱，保存。

如果条目仍未出现，社区方案建议在 Safari 打开 Apple 账户网站，使用通行密钥登录一次，再重新检查「密码」App。

这里修改的是通行密钥条目中的用户名；Apple 账户主要邮箱应已提前完成变更。无需删除通行密钥或退出 iCloud。

3. 在 Chrome 验证

  1. 用 Chrome 打开 account.apple.com。
  2. 如当前已登录，先退出网站账户，再发起通行密钥登录。
  3. 确认 Apple「密码」的通行密钥选择或确认弹窗显示新邮箱，并确认能正常登录。

4. 撤销功能开关

在「终端」执行：

sudo defaults delete /Library/Preferences/FeatureFlags/Domain/AuthKit StandardPasskeys

执行成功后，再次重启 Mac。

这条命令仅移除 StandardPasskeys 覆盖项，不会把已编辑的用户名改回旧邮箱。若此前已自行配置过同名开关，应恢复原值，而非直接删除。撤销后的条目显示与登录行为需重新验证。

注意事项

  • 这是实验性的系统功能开关，不属于 Apple 官方公开支持的修复流程；系统更新后可能失效或改变行为。
  • 只编辑确认属于自己 Apple 账户的条目，不删除通行密钥，不改动其他系统开关。
  • Reddit 方案帖称，用户名修改可同步到其他 Apple 设备；此项属于社区反馈，不包含在上述实测结论中。
